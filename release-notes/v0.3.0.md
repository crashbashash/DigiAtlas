## Maps and navigation

- Cleaner collision-floor maps with stronger height shading and clearer gaps between platforms.
- Consistent map styling across Home Server, shops and combat areas, with terrain floors where collision geometry is incomplete.
- Added Home Server service NPCs, including shops, the Save Keeper, Digivolution, Data Keeper, bank, appraiser and multiplayer reception. Hover over a marker or select it for details.
- Added Numenume River's boat route, start and end markers, and muted scenery showing its non-collision walls and banks.
- Map legends now show only relevant keys, including the number explanation only when numbered markers are present.
- Difficulty changes, room links and search results open the correct dungeon copy and floor.
- Enemy drop rooms and spawn locations now reflect the selected difficulty.
- Removed redundant map instructions and kept marker tooltips within the map edges.

## Calculators

- Added shortcuts to set the minimum level for selected equipment, the minimum weapon skill requirement, and the maximum skill available at the current level.
- Added exact equipment stat bonuses alongside rarity presets for weapons, cores and sub boards.

## Item information

- Replaced unclear pickup names with readable effects and amounts, such as X-Data and permanent stat buffs.
- Added pickup descriptions and readable elemental names while keeping original names searchable.

## After updating

Re-import your disc to refresh the data and maps. Your existing import is retained until the new import succeeds.
